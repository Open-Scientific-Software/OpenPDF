# Layered-pages icon concept

`openpdf-layered-pdf.svg` is the editable master vector. It uses original geometric paths for two upright pages and centered PDF lettering, with no fonts, embedded raster images, or external references. `openpdf-layered-pdf-preview.png` is its rendered preview.

The background is flat `#B30B00`, sampled at the owner’s request from the locally installed OpenPDF icon. No source icon artwork is included. The pages and letters were drawn independently.

The design is now used as the [OpenPDF application icon](../README.md). The preview records the original design.
